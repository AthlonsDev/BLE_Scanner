BLE Scanner

Android - Kotlin Version

This app can connect your Android phone with any Bluetooth Low Energy device.
It can receive and send data to the connected device.

It is a straightforward and lightweight application which can be installed on any Android phone.
as a free Open-Source project, it can be used as a resource to learn or explore some concepts.

The project can run on any IDE that supports the Kotlin language, like Android Studio or VSCode. Feel free to fork for your own project.
